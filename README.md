# HOLDERCARD — Historical disclosure and a new advertising space

Publication date: 3 November 2026. This is a contemporary publication describing historical records; it is not a claim of publication in 2019.

HOLDERCARD is a flat, wallet-sized, foldable physical advertising medium for brands. It converts into a smartphone stand, but the stand is the practical mechanism rather than the product's commercial category.

A front-facing branded lip remains visible in front of the smartphone during use. The advertising concept is: one-time contact → useful object → retention → repeated use → recurring brand visibility. This describes intended functionality, not independently measured advertising performance.

## Functional principle

1. The branded object is distributed as a flat card.
2. Its folding structure converts it into a smartphone support.
3. The branded front lip remains visible when a smartphone is placed on the support.
4. Continued practical use creates recurring opportunities to see the brand.

Exact construction and dimensions should be checked against authentic original filing drawings and product photographs. No new technical improvements are claimed in this document.
